## 补充：接入碰撞 + 第一人称行走（2026-09-04 晚）

- 需求：开启高斯查看器碰撞，相机一定不能穿模（室内空间 + 第一人称行走）。
- viewer 碰撞机制：config.collisionUrl（?collision= 或 ?voxel=）加载 .voxel.json(+.bin)（VoxelCollision，WebGPU 用）或 .glb（MeshCollision，MeshDebugOverlay 两者可用）；无文件则碰撞关闭。Fly/WalkController 用 SphereMover（fly，半径 CAMERA_RADIUS）/ 胶囊（walk 1.5m 高 r0.2 eye1.3 hover0.2，重力+ground probe，onEnter 用 findCylinderSpawn 落点）。官方默认模式 isObjectExperience ? 'orbit' : walk/fly —— 大场景必 orbit 无碰撞，已用 J5 补丁绕过。
- 生成命令（splat-transform 3.3.0 全局装于 AppData/Roaming/npm，voxelize 需 GPU -g 1 = RTX 3060 Laptop，25s）：
  splat-transform data/point_wlbwg.compressed.ply -r 90,0,0 --voxel-size 0.5 --voxel-external-fill --seed-pos 0,2,25 --collision-mesh faces -g 1 -w data/point_wlbwg.voxel.json
- **坐标系坑（重点）**：splat-transform voxel 输出 frame = 源数据绕 Z180（引擎 import 变换）；viewer 端把 gsplat entity 再绕 X -90（J1 默认 flip）→ 碰撞体与渲染错位 Rx(-90)。解法：生成前 -r 90,0,0 预旋转源数据。探针验证法：probe(无转)=q1、probe2(-r90)=q2，实测 q2 = q1 ∘ Rx(+90) ⇔ q2 与渲染世界逐点一致（P=(0,0,5) 渲染→(0,5,0) ✓）。seed/fill 语义：--voxel-external-fill 从包围盒边界洪泛外部并标 solid（室内密封）；seed 在内部空腔才生效，seed 出界/可达外部会跳过 fill（日志可见）。
- 产物：point_wlbwg.voxel.json(582B)+bin(70.4KB, depth6, interior 1.66K/mixed 3.86K) + collision.glb(1.9MB, 54.1K verts)；探针文件已删。
- build.mjs 新增补丁：H6 默认 collisionUrl、J4 ?coldbg=1 自动碰撞高亮、J5 有碰撞默认 walk/fly + ?mode= 强制。settings.json 设 cameras[0].initial 室内出生点 (0,2,25)（=fill seed，必在空腔；walk 自动落地无需贴地）。已验证线上 dist 含补丁、文件可访问（glb 1,951,168B）。
- 待验证：浏览器实机体验（出生点合理性、walk 手感、0.5m 体素精度是否够），如不对就调 settings 出生点或降 voxel-size。
